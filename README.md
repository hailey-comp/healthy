# JJJ Healthy Girl

친구들과 운동 기록을 남기고 주간 목표 내기를 하는 웹페이지예요.

- **기록하기**: 날짜, 종목, 운동 시간, 거리, 메모, 인증 사진
- **프로필**: 이름과 프로필 사진을 바꿀 수 있어요.
- **나만의 한 마디**: 멤버 카드의 프로필 옆 말풍선에 한 마디를 적어둘 수 있어요 (연필 버튼으로 수정).
- **숨기기**: 내 기록의 사진·메모를 친구들에게 숨길 수 있어요. 운동한 날은 멤버 현황에 그대로 반영돼요.
- **내기**: 주당 목표 운동일과 미달 벌금을 정하면 주간 현황, 미달 여부, 누적 벌금을 자동으로 계산해요. 추가 규칙도 자유롭게 적어둘 수 있어요.
- **칼로리**: 운동 종목·시간·거리·강도와 몸무게로 소모 칼로리를 추정해요 (MET 방식, 실제와 20~30% 차이 날 수 있어요).
- **내 몸 기록**: 키·몸무게·출생 연도·성별과 인바디 기록(체중, 골격근량, 체지방률 등)을 남기고 변화 그래프를 볼 수 있어요. 기본은 나만 보기이고, 기본 정보와 인바디 측정값·결과지 사진 모두 항목마다 공개 여부를 정해요. 저장 전에 무엇이 공개되는지 확인창으로 보여줘요.
- **내 페이지**: 운동 요약, 최근 12주 운동일·시간·칼로리 그래프, 종목별 시간, 인바디 항목별 변화 그래프를 한 곳에서 봐요.
- **월별 보기**: 달력에서 날짜마다 누가 운동했는지, 멤버별 한 달 합계(운동일, 시간, 거리)를 볼 수 있어요.
- **초대 링크 전용**: 친구마다 개인 링크가 있고, 링크가 없으면 아무것도 볼 수 없어요. 로그인은 필요 없어요.

## 구조

```
친구 휴대폰 ──▶ GitHub Pages (이 저장소의 index.html, app.js, style.css)
                    │  모든 요청에 개인 키를 담아 보냄
                    ▼
             Google Apps Script 웹 앱 (apps-script/Code.gs, 내 구글 계정으로 실행)
                    ├─ 구글 시트: members(참가자·키) / entries(기록) / settings(내기 규칙)
                    └─ 구글 드라이브 healthy-photos 폴더: 인증 사진
```

- 키는 구글 시트에만 저장돼요. 이 저장소에는 키가 없으니 저장소를 공개로 둬도 괜찮아요.
- 숨긴 기록의 메모와 사진 정보는 서버에서 빼고 보내요. 작성자 본인만 받아요.
- 링크로 들어오면 키를 그 기기에 저장하고 주소창에서는 지워요. 다음부터는 주소만 열어도 들어와져요.

## 설치 (처음 한 번)

> 개인 구글 계정(@gmail.com)을 쓰세요. 회사 Google Workspace 계정은 “모든 사용자” 배포나 링크 공유가 막혀 있을 수 있어요.

### 1. 구글 시트와 Apps Script

1. [Google 시트](https://sheets.new)에서 새 시트를 만들고 이름을 정해요 (예: `JJJ Healthy Girl`).
2. 메뉴 **확장 프로그램 → Apps Script**를 열어요.
3. 기본으로 있는 `Code.gs` 내용을 모두 지우고, 이 저장소의 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 붙여넣은 뒤 저장해요.
4. 왼쪽 **⚙ 프로젝트 설정 → 시간대**를 `(GMT+09:00) 서울`로 바꿔요.
5. 위쪽 함수 선택 칸에서 `setup`을 고르고 **실행**을 눌러요.
   - 권한 요청 창이 뜨면 내 계정을 고르고 허용해요. “Google에서 확인하지 않은 앱” 경고가 나오면 **고급 → (프로젝트 이름)(으)로 이동**을 눌러요. 내가 만든 스크립트라서 괜찮아요.
6. 아래 **실행 로그**에 나온 `관리자 키`를 복사해 둬요. 시트에도 `members`, `entries`, `settings` 탭이 생겨요.

### 2. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**를 눌러요.
2. 유형 선택(⚙)에서 **웹 앱**을 골라요.
3. **다음 사용자 인증 정보로 실행: 나**, **액세스 권한이 있는 사용자: 모든 사용자**로 설정하고 배포해요.
4. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사해요.
   브라우저로 열었을 때 `{"ok":true,"app":"healthy",…}`가 보이면 잘 된 거예요.

### 3. 웹페이지 설정과 GitHub Pages

1. 이 저장소의 [`config.js`](config.js)에서 `apiUrl`에 위 웹 앱 URL을 넣고 커밋해요.
2. GitHub 저장소 **Settings → Pages**에서 **Source: Deploy from a branch**, **Branch: `main` / `(root)`**로 저장해요.
   - 비공개 저장소로 Pages를 쓰려면 GitHub Pro가 필요해요. 무료 계정이면 저장소를 공개로 두세요. 키가 없으니 안전해요.
3. 1~2분 뒤 `https://hailey-comp.github.io/healthy/`가 열려요.

### 4. 친구 초대

1. 내 링크로 들어가요: `https://hailey-comp.github.io/healthy/#k=관리자키`
2. 맨 아래 **이름 변경**으로 내 이름을 정하고, **규칙 수정**으로 목표와 벌금, 시작일을 정해요.
3. **참가자 관리 → 친구 추가**로 이름을 넣고, **링크 복사**를 눌러 그 친구에게만 보내요.
4. 링크가 새어 나가면 **재발급**으로 예전 링크를 막고 새 링크를 보내요.

## 운영 메모

- **Code.gs를 고친 뒤**에는 **배포 → 배포 관리 → ✏ 편집 → 버전: 새 버전 → 배포**를 해야 반영돼요. 이렇게 하면 웹 앱 URL이 바뀌지 않아요. (새 배포를 만들면 URL이 바뀌니 `config.js`도 바꿔야 해요.)
- 시트 탭: `members`(참가자·키·몸 정보), `entries`(운동 기록), `inbody`(인바디, 처음 저장할 때 자동으로 생겨요), `settings`(내기 규칙).
- **기록은 시트에서 직접 고칠 수 있어요.** 모든 칸은 일반 텍스트이고, 날짜는 `2026-10-29` 형식이에요. `hidden` 칸은 숨김이면 `Y`, 아니면 빈칸이에요.
- **내 관리자 키를 잃어버리면** `members` 시트의 `role`이 `admin`인 줄의 `key` 칸에서 확인할 수 있어요.
- **사진**은 드라이브 `healthy-photos` 폴더에 “링크가 있는 모든 사용자 보기”로 저장돼요. 기록을 지우면 사진도 휴지통으로 가요.
- **보안 수준**: 친구가 자기 링크를 남에게 넘기면 그 사람이 친구 이름으로 기록할 수 있어요. 친구끼리 쓰는 용도로 만든 구조예요.
- 친구들의 새 기록은 1분마다, 그리고 앱으로 돌아올 때 자동으로 새로고침돼요. Apps Script 특성상 요청마다 1~2초쯤 걸려요.

## 파일

| 파일 | 역할 |
|---|---|
| `index.html`, `style.css`, `app.js` | GitHub Pages로 배포되는 웹페이지 |
| `config.js` | Apps Script 웹 앱 주소 |
| `apps-script/Code.gs` | 구글 시트·드라이브를 읽고 쓰는 서버 코드 (Apps Script에 붙여넣기) |
